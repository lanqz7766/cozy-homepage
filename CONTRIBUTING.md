# Contributing

Small, focused changes are welcome. Keep the page lightweight, readable, and usable with keyboard and reduced-motion preferences.

Before proposing a change, run `npm run check` and `npm run build`, then inspect desktop and mobile. Include screenshots for visual changes. For model changes, include the editable source and update both GLB and poster. Do not submit personal information, borrowed character models, or assets without redistribution rights.

Use an issue to share a homepage you built, report a reproducible problem, or discuss a new mascot before implementing a large change. Do not include credentials or personal contact details in bug reports.
